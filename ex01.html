selecionando os elementos DOM

posso selecionar os elementos DOM: por marca (tagname);por ID; por seletor (por css).

existem alguns comandos que nos vamos utilizar

por marca (tagname)

o comando é o getElementsbyTagname

id='p'como esta no plural: getElements... eu preciso dizer o numero do elemento que eu quero utilizar, lembrando que no JS, a contagem dos elementos começa do zero.

por Id

o comando é: getElementsbyID

preciso atribuir um ID na tag que eu quero manipular.

por ClassName

o comando é o: getElementsByClassName

por seletor de CSS

o comando é querySelector

Por name

O comando é o getElementsByName
